Glass:
  linear-gradient(138deg, #EDF9DF12 0%, #151B1559 37%, #080E0B91 100%)
  Border: #E4F4D42E
  backdrop-filter: blur(16px) saturate(115%)

Eight-digit HEX values use the final two digits for alpha.
The glass sample is illustrative: actual appearance depends on the
artwork behind it. The CSS file contains the source design's exact values.

USAGE

Use the original backgrounds to match the approved design most closely.
Use transparent versions when positioning objects over a different color
or across section boundaries. Place frosted-glass components above them.
The PNG files retain their generated resolution and have not been resized.
